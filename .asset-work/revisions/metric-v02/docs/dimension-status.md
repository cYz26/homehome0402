## 已执行的核对方式

1. 横纵方向分别按图纸尺寸链校正比例，描出外轮廓与墙体两侧；模型尺寸输入采用米制。
2. 用整体尺寸及分段尺寸的闭合关系校准位置，保留北侧退进、东侧电梯井边界与东南卧室凹角。
3. 分别记录图纸标注、图上估读、用户暂定值；未标注墙厚、洞口和低台暂估值可以替换。
4. 从实际 3D 模型导出每个房间的净尺寸与顶视轮廓，对照原图检查；有偏差先修结构再加饰面。
5. 墙面包边单独建模，按用户要求做薄。包边的外观调整不应偷偷移动墙体轴线或更改图纸尺寸。

已执行尺寸链闭合、实际 GLB 墙体参考线间距及独立重导入核对。结果见 `model/checks.json` 与 `model/validation.json`。目前可确认图纸标注分段的建模对应关系；暂估墙厚和房间实测净尺寸尚未确认。
