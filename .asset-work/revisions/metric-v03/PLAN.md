## 2. 平面与尺度

按用户房间方位描述，图上方作为北。统一使用米建模，并保存原图毫米标注。基准点拟定为南侧主体西南角的地面参考点；向东 +X、向北 +Y、向上 +Z。

| 总横向标注 | 10,500 mm | 主要横向尺度基准 |
| 总纵向标注 | 12,900 mm | 主要纵向尺度基准 |
| 南侧从西到东 | 3,500 + 4,000 + 3,000 mm | 主卧、客厅、东南卧室的标注分段 |
| 北侧从西到东 | 900 + 2,800 + 2,800 + 2,600 + 1,400 mm | 两侧退进与次卧、X 空间、厨房分段 |
| 西侧从北到南 | 3,400 + 2,100 + 1,900 + 4,900 + 600 mm | 纵向空间定位及南侧窗台带参考 |

这些是图上标注分段，不直接等同于房间净尺寸。户型轮廓有退进，东侧还有电梯井，不能把 10.5 × 12.9 直接称作建筑面积或套内面积。图上的 600 mm 分段也不直接认定为现场飘窗净深。

按尺寸链分别校准图片横纵比例，再描出墙体两侧与门窗洞口，防止扫描图拉伸影响几何。没有尺寸的位置使用图上比例估读，并标记“图上估读”；后续实测值优先替换。

空间关系：北排为西北次卧、X 空间、厨房；西侧中段为次卫、外置洗手盆及主卫；东侧中段为入口、家政柜、玄关库和电梯井邻接区；南排为主卧、客厅、东南卧室。X 空间保留现有名称与空房状态，后续再决定用途。图中的“家庭图书馆”先视为公共区域的布置意向。

## 3. 交付形态与制作方式

采用“可编辑 Blender 源模型 + GLB 交换模型 + Three.js 浏览器预览”。用可调整的尺寸表驱动建筑构件，以独立对象保留墙体、门窗、各房地面、吊顶、墙面饰面、柜体和灯具。

建议的浏览器首版功能：

- 整屋斜俯瞰：旋转、缩放、平移，显示北向与房间名称。
- 俯视核对：与图1对应，检查空间关系。
- 室内视角：图2入口、图3北侧、图4东南卧室、图5主卧四组对照机位；可以转头查看。
- 顶面和遮挡墙体的显示切换。俯瞰隐藏顶面，室内恢复完整墙顶；完整源模型始终保留。
- 全屋复位与房间定位，方便反复 review。

Three.js 的 [GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html)支持加载 glTF 模型，[OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)提供旋转、缩放和平移。上述整体应用交互仍需要在项目内实现和验证。

Blender 出参考效果图，浏览器负责交互。两种输出共用模型和材料依据，各自校验光照与色彩；不会把 Blender 渲染自动等同于浏览器显示。[Blender glTF 导出说明](https://docs.blender.org/manual/en/dev/addons/scene_gltf2.html)指出其材质体系存在差异，Area/World 光照不随 glTF 直接导出；因此纹理使用可移植的基础通道，必要时烘焙，浏览器另设对应光照。

首轮先用参数化建筑几何建立源场景。整屋精确轮廓以图纸为依据。通用物件生成器不承担户型尺度还原；特殊柜体或门窗仅在外形存在实质歧义时补充独立视图。后续若采用 Blender Assets 标准验证与导出流程，在源场景就绪后以 existing_static 路线准备正式生产计划。本文件是实施方案，不是已封存、可直接 apply 的生产计划。

## 5. 基础版范围

包括照片里的固定精装观感：墙地顶、门窗、窗台、固定柜体、可见厨房设备、灯带和筒灯。照片中可见柜体先作为样板间复现对象，实际交房是否包含另行记录。

首版空房状态不加入图1中的床、沙发、餐桌和书桌。照片中的人员、瓶装水等临时物品不作为室内构件；窗外植物和纱幕仅作为拍照场景的可切换背景，不推断为真实户外花园或阳台。客厅南侧大窗不直接改成可通行阳台门。

西北次卧、主卫、次卫等缺照片的区域：结构按照户型图，表面先采用标记清楚的统一暂定材料。未拍摄的固定柜体只做到能表达体量和通道的程度。模型用于空间与外观预览；实测不足的尺寸不用于下单或施工。

## 6. 后续可修改结构

建筑结构、现有精装、未来家具软装和拍照环境分层保存。每个房间与构件有稳定名称；模型不能合并成单一整屋网格。尺寸、材料和方案差异单独记录，避免以后换材质或家具时重建户型。

计划目录：

```text
references/        原始五图与来源校验
docs/              尺寸表、暂估项、review 记录
model/             场景生成逻辑与尺寸配置

asset_exchange/    GLB、纹理与交付记录
viewer/            浏览器预览
renders/           与照片对照的机位图
```

上面目录为初始规划。现已建立米制源场景、GLB 和浏览器应用，实际文件布局见 README.md。
