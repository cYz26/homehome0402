# 实拍沙发单主体参考图

用户要求：提供同一沙发的独立视角图，并以补充的真实照片为造型与配色依据。

本目录由内置 image_gen 逐张生成。保留灰橄榄皮革、三座软包、一个放平及两个抬起的头枕、深色胡桃木侧板、近直立的前角支撑和较短的后脚。去掉卖场背景、吊牌和独立的装饰抱枕。

每个文件只有一件沙发，不把拼图或本目录当作一张视角图上传。使用单图生成时可优先尝试 05-three-quarter.png。

这些是 AI 生成参考。正面和两侧仍有视角重建推演；背面木板与软包没有真实背面照片核实。侧视接近侧向正投影，不能作为精确图纸或尺寸依据。生成图之间的产品细节一致性已目视检查，实际 Tripo 重建及用户视觉确认尚未执行。

实际提示词、输入关系、原始生成位置、文件哈希和元数据处理记录见 [generation-record.json](generation-record.json)。输入项目副本见 inputs/source-photo.png；原始附件和 image_gen 输出均保留。元数据清理不改变解码像素。
