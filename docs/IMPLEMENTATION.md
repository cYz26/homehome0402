## 本轮锁定的交互

视线默认 1.65 m，不增加预设高度切换。PC Q 降低、E 升高。手机无摇杆：单指直接上下左右环顾；静止长按前进，松手即停；双指长按后上下滑调高度。双指操作后须全部松手才能重新移动。

## 建模保留与例外

四处平开门是与 v05 比较时明确允许变化的构件：西北门沿东墙向北打开；主卧和东南卧室门改为北端铰链，分别向西及向东打开；入户门向东外开。门洞不变，东南门叶留 4 cm 合页偏移以避让墙面。

所有非门部件的边界和三角形数量与 v05 保持一致。复杂精装拓扑继续使用哈希锁定的 v05 模板，JSON 控制位置、尺寸和材质参数；复杂细部重塑仍需更新模板，不能把模板来源误称为全部几何均由 JSON 原生描述。
