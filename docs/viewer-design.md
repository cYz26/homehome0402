## 历史密码访问与路径 · 2026-10-08

Cloudflare 网站使用 `/` 根路径；本机 Vite 保留直接设计预览。未登录打开网站显示暖灰色密码页，无需外部字体、图片或第三方资源。输入密码后发放 Secure / HttpOnly / SameSite=Strict Cookie，有效期为 24 小时；修改密码或会话密钥使旧登录失效。密码不进入 URL、分享链接、静态资源或前端 JavaScript。登录后的分享恢复保留查询和 `#view` 片段，站内旧 `/homehome402/` 路径在认证后跳到根路径。

Worker 必须先于所有静态资源执行；未认证的清单、图片、图纸、解码器及 GLB 请求均返回 401，缺少配置返回 503。密码错误提示留在入口，登录尝试按 IP 限制为每个 Cloudflare 节点 10 次 / 60 秒，同一网络使用者共用限额；它不是全局精确配额。登录 POST 仅允许同源、表单体最多 8 KiB，重定向目标限定同源路径。模型回复直接转发响应流，底层忽略 Range 时按请求范围截取流，保留 If-Range 和 ETag。客户端响应为 `private, no-store`，底层 Static Assets 边缘缓存及已验证模型的浏览器哈希缓存保留；已经下载的内容无法远程撤回。

验证记录见 [QA](QA.md#workers-密码发布迁移--2026-10-08)及原发布收据；该入口属于历史 Workers 部署。

## 空间阅读

逻辑构件与网格分离：690 个原始部件归属 73 个稳定构件 ID；共享墙可关联多个空间。压缩只在同一构件与显示层内部合并，外部 JSON 提供尺寸、材质与注释。所有 11 个空间都有多边形和明确面积口径。

SVG 平面图可选择房间及构件；3D 选取反向更新平面图、属性与房间按钮。门扇增加透明点击范围，平面构件支持键盘 Enter / Space。手机属性面板放在画布下方，可折叠。

水平 Z、东西 X、南北 Y 使用 Three.js 裁切平面；选取使用同一半空间规则，阴影跟随材质剖切。闭合截面以模型三角形实际交线生成，开放或退化交线不凭空封闭。旧 upper/lower 分件仍保留以兼容历史模板，展示不再靠隐藏 upper 层实现切高。

## 漫游

默认眼高 1.65 m，无预设高度切换。PC WASD 移动、鼠标或方向键上下左右环顾、Q 降/E 升，视线限定 1.25–1.90 m。

手机手势：

1. 单指滑动立即改变水平与俯仰方向；滑动浏览不会等待长按。
2. 静止按住 280 ms 开始前进；启动后仍可滑动环顾，松手即停。
3. 双指同时按住 350 ms 后，上下滑调整高度；双指存在时停止前进。
4. 双指操作后，必须全部离屏才能重新开始移动。失焦、切后台、指针取消及离开交互区域均清空输入。

三维区域（含画布上方提示）禁用文字选中及移动 Safari 长按弹层；室内/漫游模式下，画布用非 passive 的 `touchstart` / `touchmove` 取消浏览器默认行为，并拦截 `selectstart` / `contextmenu`，避免长按复制打断前进。移动和选取仍统一由 Pointer Events 驱动，事件监听随查看器销毁释放。区域外正文及分享地址保留正常选中复制。

导航使用完整建筑/固定设施的独立碰撞数据。单层胶囊的水平圆形足迹半径为 0.19 m，并按障碍高度过滤；移动以小步连续检查并沿墙滑动。路径搜索基于从同一碰撞生成的可通行网格，禁止对角穿角；剖切及隐藏不修改导航。最大帧间隔为 0.1 s，细分为最多 1/60 s 步长，恢复后台不会补算整段离开时间。

## 画质与生命周期

标准：使用屏幕原生像素比、32 样本 AO、4096 阴影、1024 主卫镜面、4× MSAA（按 GPU 支持）及 SMAA。纹理不再降采样，使用全尺寸高质量 KTX2；不启用 UASTC RDO 画质交换。流畅仅由用户手动选择：像素比上限 1，关闭 AO、实时阴影和实时镜面。室内补光绑定模型中的灯具位置，不跟随相机。

场景按需绘制，持续移动和相机过渡会逐帧更新；静止画面不重复绘制额外尾帧，当前 AO / SMAA 合成没有时间累积。页面隐藏或交互区域离开视口时暂停。资源载入后先实际渲染一帧再隐藏加载预览。重试、高清切换、取消及页面返回会释放旧模型、材质、纹理、解码器和监听器。分享链接校验版本字段、枚举、ID 与数值范围后恢复。

帧时导出只描述当前浏览器会话；真实手机测试与响应式模拟单独记录。

## 模型加载 · 2026-09-15

用户后续明确要求首页提前加载：主视觉解码并经过绘制帧后，在浏览器空闲时并行下载查看器代码、导航和模型，空闲调度最长等待 1.5 秒；不支持空闲 API 时以普通任务调度。预加载保持首页界面不变，不创建 WebGL 画布或提前进行 GPU 渲染。页面在后台时推迟启动，回到前台可继续调度。首页的关键呈现资源继续受 1 MiB 预算约束，呈现后的 3D 预加载按 16 MiB 预算计。

进入 3D 时接管同一份进行中或已完成的准备任务，复用进度与内存中的模型字节，不重新下载；离开页面会取消准备任务。预加载失败保持静默并释放失败任务，显式进入时可重新尝试；取消显式加载后不会在后台自动重启。高清模型仍仅在用户选择时加载。

4 MiB 以上模型先以 64 KiB 请求确认服务器支持 Range，再用四个并行请求读取剩余字节。每段核对 Content-Range，存在强 ETag 时用 If-Range 绑定同一资源；服务器忽略 Range 时使用该完整响应，不重复下载，分段信息异常则回退为普通完整下载。

模型交给解析器前核对发布清单的字节数和 SHA-256，不修改 GLB、纹理尺寸、材质或画质参数。完整且校验通过的模型按 URL + SHA-256 存入浏览器 Cache Storage；再次打开可直接使用，旧哈希不能冒充当前发布版本。每个模型 URL 只保留最近写入的版本，网页/高清模型分别缓存；存储不可用时继续正常网络加载。

进度明确区分下载、解析模型与纹理、绘制三维画面；百分比仅描述下载。未装入模型时动画循环不绘制被预览遮住的空场景，仍在实际绘制完整模型首帧后关闭预览。取消会中止全部分段请求，并立即结束对未完成代码导入/解析的等待；重试和高清切换保留原有生命周期及机位恢复。

## 2026-09-15 切面显示修正

主画面与 SSAO 的单一替换材质原先使用了不同的裁切规则：被切掉的墙体仍参与环境遮蔽，形成随缩放变化的错误明暗。现在按原材质生成法线材质，保留相同剖切平面、朝向和深度偏移；玻璃不作为不透明遮挡物，截面保持独立。正常 AO、阴影和镜面继续开启。临时选中材质释放时也回收对应法线材质。

GLB 的同一实体可能按材质拆成多个 primitive。截面轮廓先汇集同一父节点下的这些表面，再闭合剖口，避免竖向剖切缺失顶边。物理和导航继续使用完整建筑，不受展示剖切影响。
