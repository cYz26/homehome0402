# 网站与查看器设计 · metric-v06

## 页面与内容

沿用暖灰、灰绿风格。页面顺序为主视觉、项目概览、交互模型、空间说明、材质细节、图纸与资料。首页先显示响应式 WebP，进入交互区域或点击“探索 3D”后再加载 Three.js、导航数据与模型。

默认参考图是当前源模型的 Cycles 渲染。另提供根据当前模型与脱敏实拍更新的 AI 示意图，明确标注来源；原始图纸、实拍与历史 v05 示意独立保留。图纸尺寸链、模型估算面积与现场实测值不混用。

## 空间阅读

逻辑构件与网格分离：690 个原始部件归属 73 个稳定构件 ID；共享墙可关联多个空间。压缩只在同一构件与显示层内部合并，外部 JSON 提供尺寸、材质与注释。所有 11 个空间都有多边形和明确面积口径。

SVG 平面图可选择房间及构件；3D 选取反向更新平面图、属性与房间按钮。门扇增加透明点击范围，平面构件支持键盘 Enter / Space。手机属性面板放在画布下方，可折叠。

水平 Z、东西 X、南北 Y 使用 Three.js 裁切平面；选取使用同一半空间规则，阴影跟随材质剖切。闭合截面以模型三角形实际交线生成，开放或退化交线不凭空封闭。旧 upper/lower 分件仍保留以兼容历史模板，展示不再靠隐藏 upper 层实现切高。

## 漫游

默认眼高 1.65 m，无预设高度切换。PC WASD 移动、鼠标或方向键上下左右环顾、Q 降/E 升，视线限定 1.25–1.90 m。

手机手势：

1. 单指滑动立即改变水平与俯仰方向；滑动浏览不会等待长按。
2. 静止按住 280 ms 开始前进；启动后仍可滑动环顾，松手即停。
3. 双指同时按住 350 ms 后，上下滑调整高度；双指存在时停止前进。
4. 双指操作后，必须全部离屏才能重新开始移动。失焦、切后台、指针取消及离开交互区域均清空输入。

导航使用完整建筑/固定设施的独立碰撞数据。单层胶囊的水平圆形足迹半径为 0.19 m，并按障碍高度过滤；移动以小步连续检查并沿墙滑动。路径搜索基于从同一碰撞生成的可通行网格，禁止对角穿角；剖切及隐藏不修改导航。最大帧间隔为 0.1 s，细分为最多 1/60 s 步长，恢复后台不会补算整段离开时间。

## 画质与生命周期

标准：使用屏幕原生像素比、32 样本 AO、4096 阴影、1024 主卫镜面、4× MSAA（按 GPU 支持）及 SMAA。纹理不再降采样，使用全尺寸高质量 KTX2；不启用 UASTC RDO 画质交换。流畅仅由用户手动选择：像素比上限 1，关闭 AO、实时阴影和实时镜面。室内补光绑定模型中的灯具位置，不跟随相机。

场景按需绘制，持续移动和相机过渡会逐帧更新；页面隐藏或交互区域离开视口时暂停。资源载入后先实际渲染一帧再隐藏加载预览。重试、高清切换、取消及页面返回会释放旧模型、材质、纹理、解码器和监听器。分享链接校验版本字段、枚举、ID 与数值范围后恢复。

帧时导出只描述当前浏览器会话；真实手机测试与响应式模拟单独记录。

## 2026-09-15 切面显示修正

主画面与 SSAO 的单一替换材质原先使用了不同的裁切规则：被切掉的墙体仍参与环境遮蔽，形成随缩放变化的错误明暗。现在按原材质生成法线材质，保留相同剖切平面、朝向和深度偏移；玻璃不作为不透明遮挡物，截面保持独立。正常 AO、阴影和镜面继续开启。临时选中材质释放时也回收对应法线材质。

GLB 的同一实体可能按材质拆成多个 primitive。截面轮廓先汇集同一父节点下的这些表面，再闭合剖口，避免竖向剖切缺失顶边。物理和导航继续使用完整建筑，不受展示剖切影响。
