# 查看器设计与实现边界

v05 是用户确认的房屋外观基准。查看器为这套模型补充必要的导航控件；不新增房屋装潢。图像参考比例服从原图尺寸链。

界面采用整屏 3D 画布、68 px 顶栏、228 px 左侧空间列表。模型占主要面积，浅暖灰背景 #f3f1ec，近白面板 #fafaf7，深灰正文 #30372f，灰绿选中态 #465344，细边框 #dedfd7，圆角 8 px。中文系统无衬线字体，标题 20 px，控件 13 px，辅助文字 12 px。无营销区、装饰卡片、虚构统计。

主要控件：立体 / 俯视 / 室内，房间定位，房间标签，显示尺寸，复位，参考图，尺寸依据。室内模式增加拖动转头说明与机位名称，这是用户要求的四个实景对照机位所需。手机折叠左侧栏为可打开的空间面板，保证画布可用。

生成的 UI 概念仅供本轮实现排版参考，无需重复请求用户批准。真实画布必须加载米制 GLB，不以图像背景替代模型。以尺寸链修正生成参考的客厅宽度、房间进深属于已约定的必要修正。
