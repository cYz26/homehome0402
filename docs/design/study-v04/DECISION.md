## 制作路线与核对

四个家具都是规则刚性静物，选择独立参考 → 本地 Blender 参数化建模；椅子按机械部件单元处理，不需要角色 Tripo 路线。原用户桌椅图、已确认图、三个独立解释参考及精确文件摘要绑定于 selection / alignment 记录；解释图不替代厂家图。项目 AGENTS 要求从 apartment.json 及原生建模管线重建，因此采用项目管线，Blender Assets 的 route-check 作来源预检；不声称执行了插件 apply/export。插件 doctor 已确认 Blender 5.2.1 可用，插件 Python 锁定依赖和 MCP 配对不可用，不影响项目已有 CLI 管线。

先实际查看中性模型正面/侧面/斜面体量，再完成书本、玻璃、织网与暖光；最终独立导出/重导入、同源 Cycles 及网页实时画面分别检查。保存 packed Blend、GLB、实际测量和审查记录。为保持全纹理并遵守单文件 25 MiB，书房家具作为第三个互斥模型包，与房屋/沙发共同加载、选取、剖切和碰撞。

网站增加书房空间卡片和专属细节机位，图廊保留两张已确认 AI 图并明确来源；实际模型渲染单独标识。当前实际 3D 审美接受、现场/厂家尺寸、坐人承重和真机性能仍与已确认 AI 外观分开记录。发布须经完整 Actions 验证并回读线上版本、摘要与所有模型分包 Range。
