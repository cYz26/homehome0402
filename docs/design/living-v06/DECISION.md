# 85 寸电视与实拍墙面 v06 → metric-v11 · 2026-10-09

用户先要求参考墙面照片保持电视墙效果一致并同步 3D，随后补充“电视设定为 85 寸的大电视，下方是一个横排悬空柜，旁边放一组立柜”，要求考虑一端石材面的立柜位置。这些当前要求取代 [v05](../living-v05/DECISION.md) 的暂定 75 寸和原错落柜保留方案；历史版本与原输入均保留。

墙面照片是灰米色竖向分缝面板、深色细收边 / 左侧墙体侧立面、窗侧灰绿石纹饰面和竖向暖光缝的外观依据。第二张图只用于电视 / 家具形式，不能把其中的房间、窗户、吊顶或茶几复制到 Home 402。四张输入、原始文件摘要和无像素变化的项目副本清理记录见 `references/revisions/tv-wall-20261009/intake.json`。

本轮采用 85 寸 16:9 关闭屏幕，约 1.898 × 1.074 m 外形、8 mm 边框，中心距模型地面 1.35 m。用户随后要求降低悬空柜、对齐实拍插座、表现立柜凸出墙面的深度，并把双门收窄为单门，要求展示其与旁边门洞的整体关系。横排柜现暂设 3.08 × 0.40 × 0.30 m，柜底距完成地面 0.12 m（模型绝对高度 0.136 m）、柜顶距完成地面 0.42 m，四个平整封闭抽屉，低柜配暖色下照。立柜收窄为 0.45 × 0.40 × 2.56 m 单门柜，靠走廊的一端布置，离左侧深色立边留 2 cm；两柜的正面约凸出主饰面 0.41 m。石材面和竖向灯缝留在靠窗端，悬空柜止于灯缝之前。柜体尺寸、色温及安装高是方案假设，不是厂家或现场测量。

实拍主面板按四角透视校正后观察到两组基本同高的黑色插座：左为横向三联面板，右为单面板，分别位于主面板宽度约 48% 与 66% 处；映射到当前模型为 t=10.26 / 10.92 m、中心高度约 0.355 m。该布局取自实拍，尺度仍依模型墙宽推断。低柜遮住两组插座的正面，但不移动原插座：背后预留 75 mm 服务空腔、可拆背板和抽屉检修路径；支架避开插座。实际插头、散热、五金及安装承重待现场复核。

立柜放在走廊侧是执行任务时的推荐布局，用于实际 3D 复核，不记为用户已确认该具体摆放。主要理由是让窗侧石材和灯带完整露出；同时核对门洞、全开门、电视边缘和通道。左侧低柜端保留原台灯并避让大屏，落地灯移到阅读椅一侧；柜面小物改为低矮书本 / 播放设备，避免遮挡屏幕和灯缝。

模型继续由 `model/apartment.json` 驱动；电视墙主饰面相对结构墙凸出约 0.22 m，黑色长条为墙体朝门洞的侧面，不再作为宽的正面装饰条。按最新用户红框实拍将相邻卧室门洞调整为简洁平口、顶与饰面 2.62 m 暂时对齐；原门宽 0.90 m、平面位置、铰链和全开方向保留。具体门高与饰面深度是照片解释，不是实测值；仅改该门及洞口上方的参数几何，锁定 v05 精装模板保留。电视和横柜继续保留 `living-art-panels` / `living-modular-cabinet` 的稳定逻辑 ID，新立柜、面板和石材具有独立查询归属；下 / 上层分段用于原剖切约定，室内没有额外横向分缝。原 4K 沙发、多功能桌 / 椅凳、中央无茶几、窗景和其他建筑保留。

从观察过的 metric-v10 场景与 JSON 修订静态家具，路线为 `revise_static / existing_blender`。新墙面 / 家具组合的独立形体参考为 `references/generated/tv-wall-20261009-r2/independent-wall-r3.png`，是在两张用户图基础上生成并由执行代理选取的解释图；主依据仍是用户原图和显式需求。比例、关键特征与允许的推断见 [外观对照](FIDELITY.md)。metric-v10 源、资源和验证完整保留，规格与当前生成代码快照在 `model/baseline-v10/`。
