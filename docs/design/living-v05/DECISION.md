# 客厅电视墙 v05 → metric-v10 · 2026-10-09

用户要求“将客厅沙发对面的墙面壁画改为电视，就还是电视墙的布置，下面的电视柜也可以给几个方案效果图看下”。这项当前要求取代 v02–v04 的无电视约束，原版本与证据继续保留。沿用 [v04](../living-v04/DECISION.md) 的建筑、沙发、餐学办公桌、开放中央空间和暖色氛围。

从 `model/apartment.json` 将原单幅画替换为深色屏幕、薄边框及支架组成的壁挂电视，再由已有 Blender 算法重建。保留逻辑 ID `living-art-panels` 和网格节点用于既有查询 / 分享兼容，名称与材质更新为电视。暂设 75 英寸、1.66 × 0.934 m、中心距地 1.35 m；这是方案尺寸，未指定品牌 / 型号、未核对现场安装条件。台灯移至右侧高柜外端，以免遮挡屏幕。

电视柜提供三种同机位 AI 对照，分别是 A 悬浮浅木柜、B 落地胡桃木收纳柜、C 高低错落胡桃木组合柜。三张图保持房间、沙发、窗户和照明参照一致；整体效果图只将原大画改成电视。图片、提示词和来源见 [方案记录](../../../references/generated/tv-wall-20261009/REVIEW.md)。生成图不证明精确尺寸，也不是 Blender 渲染或实拍。

新柜方案尚未获用户选择。真实 3D 暂沿用原 3.80 × 0.42 m、0.78 / 0.50 / 1.16 m 的错落柜；不将 C 概念图细节当作已确认柜体修改。中央仍无茶几。当前只更新本机模型及网站预览，本轮用户没有要求提交、推送或远程发布。

源选择为 `revise_static / existing_blender`：从已观察的 metric-v09 JSON、家具生成器及完整 Blend 修订电视墙显示构件。其余家具和建筑源按原参数重建；旧 v09 规格、测量、验证、清单与交付记录快照保存至 `model/baseline-v09/`。当前版本全部派生物以 metric-v10 清单绑定；技术检查、实际画面、用户选择、真机与远程发布分别记录。
